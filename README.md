# Moto-VE

Smart Vehicle Recommendation Platform built using Flutter and Firebase.

## Features
- Smart vehicle recommendation
- Advanced filtering
- EMI estimation
- Vehicle comparison
- Favorites management
- Detailed specification pages
- Responsive UI design

## Tech Stack
- Flutter
- Dart
- Firebase
- Cloud Firestore
- Firebase Authentication

## Getting Started

```bash
flutter pub get
flutter run
```
